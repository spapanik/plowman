# Installation

# Using uv

We recommend using [uv] for the installation of `plowman` as it provides
an isolated environment for the package, preventing any dependency conflicts.

The minimum python version needed is `3.10` but as uv is used, version 3.14
is preferred.

To install `plowman` using uv, run the following command in your terminal:

```console
$ uv tool install --python 3.14 plowman
```

[uv]: https://github.com/astral-sh/uv
